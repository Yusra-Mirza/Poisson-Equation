# Poisson Equation (Team 11 Bits)

## 📌 Overview

This project focuses on solving the **2D Poisson equation** for an arbitrary density distribution using three numerical iterative methods implemented in **C**:

* **Jacobi Method**
* **Gauss–Seidel Method**
* **Successive Over-Relaxation (SOR)**

The goal is to compute the potential on a 2D grid and **visualize the results** to check consistency and compare the efficiency of the three methods.

---

## 🎯 Project Objectives

* Compute the potential on a 2D grid for a given density.
* Implement **Jacobi**, **Gauss–Seidel**, and **SOR** iterative solvers.
* Visualize the computed potentials for verification.
* Compare convergence speed and efficiency of the three methods.

3. Visualize the output using Python, or any plotting tool.


## 📊 Visualization tools

The computed potential values can be plotted using tools such as:

* **Python (Matplotlib)**
* **NumPy**
This helps verify if the solutions converge correctly.


## 📈 Comparison

The project compares the following:

* Number of iterations required
* Convergence rate
* Efficiency improvement (especially from SOR)


## 🛠️ Requirements

* C Compiler (GCC recommended)
* Python for visualization
